# E-Commerce Customer Segmentation using Machine Learning

## 1. Project Overview
This project focuses on dividing e-commerce customers into different groups based on their purchasing behaviour. Customer segmentation helps businesses understand their customers and create better marketing strategies.

## 2. Objectives
- Understand customer purchasing behaviour.
- Perform RFM analysis.
- Group customers using clustering algorithms.
- Visualize customer segments.
- Create marketing strategies for different customer groups.

## 3. Dataset
The project uses an e-commerce retail dataset containing customer purchase information.

Important features:
- CustomerID
- InvoiceDate
- Quantity
- UnitPrice


## 4. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 5. Algorithms and Techniques
- RFM Analysis
- K-Means Clustering
- DBSCAN Clustering
- Principal Component Analysis (PCA)
- t-SNE Visualization

## 6. Project Workflow
1. Load the dataset.
2. Clean and preprocess the data.
3. Calculate Recency, Frequency and Monetary values.
4. Apply feature scaling.
5. Perform K-Means and DBSCAN clustering.
6. Apply PCA for dimensionality reduction.
7. Visualize customer groups using t-SNE.
8. Identify customer personas.
